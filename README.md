# Project 360

RMS360 — Premium Enterprise Website Homepage

Build a premium, modern, responsive homepage for RMS360, an intelligent remote monitoring and infrastructure management platform for critical infrastructure.

The website should feel like a serious enterprise technology product comparable to leading global industrial IoT, infrastructure monitoring, energy technology, and remote operations companies.

Do NOT make this look like a generic SaaS template.

Do NOT copy the design of 6th Energy or AIO Systems. Use them only as general inspiration for the category. RMS360 must have its own stronger visual identity.
